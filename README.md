# 💪 筋トレ記録アプリ「LiftLog」

## サービス概要
- 日々の筋トレ記録を **シンプルに入力・管理** できるアプリ  
- 重量・回数から **自動で総重量を計算**  
- **トレーニング日数レポート** で成長を可視化  
- **Bootstrap + Hotwire** による直感的でストレスのないUI  

---

## 現在の開発ステータス（MVPリリース時）

### 実装済み機能
| カテゴリ | 内容 |
|-----------|------|
| ユーザー管理 | Devise によるユーザー登録・ログイン機能 |
| トレーニング管理 | ワークアウト（トレーニング日）・セット（重量・回数）の登録・編集・削除 |
| カテゴリー管理 | 胸・肩・腕・背中・脚・腹・有酸素を固定カテゴリーとして登録 |
| 種目管理 | カテゴリー別に種目を追加・編集・削除 |
| レポート機能 | トレーニング日数・総挙上重量を週・月単位で集計表示 |
| UI | Bootstrapを用いた統一デザイン、スマホ対応のレスポンシブ設計 |

## サービスの目的・開発背景
自分自身、筋トレを続ける中で「とにかくシンプルに記録ができるアプリが欲しい」「成長を簡単に感じられるような機能が欲しい」と感じた経験から開発しました。  
日々の積み上げを見える形にし、**“継続のモチベーション”** を支えるアプリを目指しています。  
また、筋トレのように「積み上げ型の努力」を記録し、成長を感じられる設計は、  
自分の開発スタイル（小さな改善を積み上げて完成させる）にも通じています。

## 競合調査と差別化ポイント

### 競合サービス比較

| サービス名 | 特徴 | 感じた課題点 |
|-------------|------|--------------|
| **Workout Record** | 種目を自由に登録できる | 過去日付への記録追加不可。種目別推移グラフなどのレポート機能の不足。 |
| **EveryWorkout** | タイマー付きでトレーニング管理 | ユーザーが種目を自由に登録できず、テンプレートのみ。カレンダーがなく、日々の記録が追いにくい。タイマー設定を毎回しなければならず煩雑。 |

### LiftLogの差別化ポイント

| 項目 | 差別化内容 |
|------|-------------|
| **操作性** | シンプルな入力をするだけで総重量やトレーニング日数を自動算出。前回記録を自動入力して手間を最小化。 |
| **分析性** | 種目別・部位別のグラフで成長を「見える化」。 |
| **モチベーション維持** | カレンダーでトレーニング履歴を視覚化。レポート機能で継続の達成感を支援。 |

## まとめ
「LiftLog」は、トレーニングの記録を“続けられる”ことを第一に考えて設計したアプリです。  
難しい分析や複雑な操作ではなく、**日々の積み重ねをシンプルに可視化**することを目的としています。  

記録をつけるだけで、  
- 総重量やトレーニング日数が自動で算出され、  
- 習慣の定着や成長の実感をサポートします。  

開発を通じて、コードやUIの改善を「積み上げる」プロセスが、筋トレそのもののように感じられました。  
LiftLogは、そんな **“努力の見える化”を支援するツール**として、これからも進化を続けていきます。

継続が成果をつくる。  
**LiftLogは、日々の積み重ねを未来につなぐアプリです。**
