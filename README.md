# 💪 筋トレ記録アプリ「LiftLog」

## サービス概要
- 日々の筋トレ記録を **シンプルに入力・管理** できるアプリ  
- 重量・回数から **自動で総重量を計算**  
- **トレーニング日数レポート** で成長を可視化  
- **Bootstrap + Hotwire** による直感的でストレスのないUI  

---

## 現在の開発ステータス（MVPリリース時）

### 実装済み機能
| カテゴリ | 内容 |
|-----------|------|
| ユーザー管理 | Devise によるユーザー登録・ログイン機能 |
| トレーニング管理 | ワークアウト（トレーニング日）・セット（重量・回数）の登録・編集・削除 |
| カテゴリー管理 | 胸・肩・腕・背中・脚・腹・有酸素を固定カテゴリーとして登録 |
| 種目管理 | カテゴリー別に種目を追加・編集・削除 |
| レポート機能 | トレーニング日数・総挙上重量を週・月単位で集計表示 |
| UI | Bootstrapを用いた統一デザイン、スマホ対応のレスポンシブ設計 |

## サービスの目的・開発背景
自分自身、筋トレを続ける中で「とにかくシンプルに記録ができるアプリが欲しい」「成長を簡単に感じられるような機能が欲しい」と感じた経験から開発しました。  
日々の積み上げを見える形にし、**“継続のモチベーション”** を支えるアプリを目指しています。  
また、筋トレのように「積み上げ型の努力」を記録し、成長を感じられる設計は、自分の開発スタイル（小さな改善を積み上げて完成させる）にも通じています。

## 競合調査と差別化ポイント

### 競合サービス比較

| サービス名 | 特徴 | 感じた課題点 |
|-------------|------|--------------|
| **Workout Record** | グラフや統計など、分析機能が充実しておりデータから成長を可視化できる | 部位や種目のテンプレートがなく、初回設定時にすべて手動登録する必要があるため導入時の手間が大きい |
| **EveryWorkout** | ワークアウト記録機能にタイマーが付いており、セット間のインターバルを管理できる | ユーザーが種目を自由に登録できず、テンプレートで用意された種目しか記録できない。カレンダー機能がなく、過去記録が追いにくい。 |

### LiftLogの差別化ポイント

| 項目 | 差別化内容 |
|------|-------------|
| **操作性** | ワークアウトの登録が直感的。前回記録を自動入力するため、フォーム入力の手間（重量を思い出す作業）を最小化し、毎日の記録がスムーズに。 |
| **分析・可視化** | 種目別・部位別のグラフや総重量推移で、成長を数字と視覚で確認可能。単なる記録ではなく、達成感を伴う分析体験を提供。 |
| **習慣化サポート** | カレンダーに記録を自動反映し、週間・月間レポートでトレーニング習慣を可視化。継続のモチベーション維持まで含めた一貫した体験を実現。 |

## ユーザーの獲得方法

- **SNS発信**：TwitterやInstagramなど、トレーニー層が多いSNSでの発信を中心に展開  
- **訴求軸**：「シンプル操作 × 成長の見える化」を前面に打ち出す  
- **口コミ展開**：友人やトレーニー仲間へのテスト利用を通じ、フィードバックを反映  
- **継続率向上施策**：カレンダー・レポート機能を活用した「習慣化サポート」を強調

## まとめ
「LiftLog」は、トレーニングの記録を“続けられる”ことを第一に考えて設計したアプリです。  
難しい分析や複雑な操作ではなく、**日々の積み重ねをシンプルに可視化**することを目的としています。  
記録をつけるだけで、総重量やトレーニング日数が自動で算出され、習慣の定着や成長の実感をサポートします。  
開発を通じて、コードやUIの改善を「積み上げる」プロセスが、筋トレそのもののように感じられました。  
LiftLogは、そんな **“努力の見える化”を支援するツール**として、これからも進化を続けていきます。

継続が成果をつくる。  
**LiftLogは、日々の積み重ねを未来につなぐアプリです。**
